# Security policy

## Reporting a vulnerability

If you find a vulnerability in this deployment (the configuration, the theme, the landing and legal pages, or the CI gates in this repository), **do not open a public issue or pull request**. Write to:

**security@samourai.coop**

Say what you found, how to reproduce it, and what it exposes. We acknowledge the report, agree a fix and a disclosure date with you, and credit you unless you ask us not to.

## Upstream

A vulnerability in La Suite Meet itself, reproducible on unmodified upstream, belongs to its maintainers: see the [upstream security policy](https://github.com/suitenumerique/meet/blob/main/SECURITY.md). If you are unsure which side it is on, write to us and we forward it.

## Supported versions

Only the current deployment from `main` is supported.
