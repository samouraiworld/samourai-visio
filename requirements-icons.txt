# Pinned by version AND by hash, so this job resolves the same artefact
# every run — the rule the workflow already applies to every action SHA.
# Only the artefacts the runner can use: CPython 3.12 manylinux x86_64,
# plus the sdist, so a platform change fails loudly instead of quietly
# resolving something else.
#
# Regenerate — one command per artefact, then hash the results:
#
#   pip download Pillow==<version> --no-deps --only-binary=:all: \
#       --python-version 3.12 --platform manylinux_2_17_x86_64 -d .
#   pip download Pillow==<version> --no-deps --only-binary=:all: \
#       --python-version 3.12 --platform manylinux_2_28_x86_64 -d .
#   pip download Pillow==<version> --no-deps --no-binary=:all: -d .
#   pip hash *.whl *.tar.gz
#
# One `--platform` per invocation: passing both to a single command resolves
# one best match and silently returns a single wheel.
#
# NOT `--no-binary :none:`. pip reads `:none:` as "empty the set of packages
# for which binaries are disallowed" — so it *allows* binaries and downloads
# one wheel for whatever machine is running, which on a laptop is a macOS ARM
# wheel this runner can never use. That was the instruction here before, and
# it would have produced the wrong file at the next version bump.
#
# The cp312 musllinux wheel is deliberately absent: this job runs on
# ubuntu-latest, which is glibc. Adding it would widen what pip may accept
# without widening what the job can run.
